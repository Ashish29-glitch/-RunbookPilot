Runbook Vault & Architecture Overview

RunbookPilot is an enterprise-grade Self-RAG assistant built for on-call engineers. It uses LangGraph to orchestrate stateful retrieval-augmented generation loops with rigorous quality checks.

Qdrant Vector Database

Stores pre-chunked internal runbooks, SOPs, and postmortems embedded via Hugging Face models for lightning-fast semantic retrieval.

Groq LLM Acceleration

Powered by high-throughput Groq production models to evaluate relevance, verify generation support (IsSUP), and grade usefulness (IsUSE).

Tavily Web Search Fallback

When internal corporate knowledge comes up empty, the graph rewrites queries and queries Tavily to pull verified real-time technical documentation.

SQLite Checkpoint State

Persists conversation turns across multi-step troubleshooting sessions for complete contextual awareness and audit trails.

System Audit Trail

Real-time telemetry and execution logs stored securely in local SQLite databases for post-incident review.
